Liver Function Indicators & Alcohol Consumption — Regression Study
Portfolio project | Applied Data Science & AI
Method: Multiple Linear Regression
Dataset: UCI Liver Disorders (ID 60)

Project overview
This project investigates whether five liver-related blood-test measurements contain useful statistical information for estimating an individual's reported daily alcohol consumption in the UCI Liver Disorders dataset.

The goal is not to diagnose liver disease. The dataset does not contain a liver-disease diagnosis. The project is an exploratory regression study: understand the data, examine associations, build and evaluate a baseline and a multiple linear regression model, inspect model assumptions, and communicate limitations.
Research question
How accurately can daily alcohol consumption be estimated from five liver-related blood-test measurements in this dataset, and how should the model's results be interpreted?
Supporting questions
1. Which blood-test measurements have the strongest individual association with the drinks target?
2. How well does a multiple linear regression model perform on a held-out test set compared with a simple mean-prediction baseline?
3. Do the regression diagnostics suggest issues such as non-linearity, heteroskedasticity, multicollinearity, or influential observations?
4. How stable is the model under cross-validation, and what are the limitations of using it outside this dataset?
